# Agent Connector for WP — Ability Pack: Contact Form 7

Turns [Contact Form 7](https://wordpress.org/plugins/contact-form-7/) into a full-coverage
MCP surface. It registers abilities via the WP Abilities API, which
[Agent Connector for WP](https://github.com/soflyy/agent-connector-for-wp) auto-exposes as
MCP endpoints — with permission checks, domain-lock, and audit logging injected for you
(this pack contains **no** auth code).

Generated by the [`wp-mcp-generator`](https://github.com/soflyy/mcp-for-everything-wp) skill.

- **Requires:** `agent-connector-for-wp`, `contact-form-7`. Target CF7 v6.1.x.
- **Vendor namespace:** `cf7/…`

## What an agent can do

Everything a human admin can do in the CF7 editor — driven through task-level verbs that take
only the delta you care about:

- **Forms:** `list-forms`, `get-form`, `create-form`, `copy-form`, `delete-form`,
  `update-form-properties` (title/locale).
- **Fields:** `add-field`, `update-field` (delta-merged), `remove-field`,
  `set-form-template` (raw escape hatch), `list-field-types` (introspection).
- **Mail:** `update-mail` (primary + secondary autoresponder), `list-mail-tags`.
- **Messages:** `update-messages`, `list-message-keys`.
- **Additional settings:** `update-additional-settings` (set/unset keys),
  `list-additional-settings-keys`.
- **Validate & test:** `validate-form` (CF7's config validator), `submit-form`
  (drives the real submission pipeline; skips mail by default).

Start with `cf7/list-forms` to find a form, `cf7/get-form` to read its full state, then use
the verbs above. The `list-*` abilities are introspection: call them to learn valid field
types, mail-tags, message keys, and settings keys instead of guessing.

## How it works (design)

Every mutation routes through CF7's own canonical save path, `wpcf7_save_contact_form()`, so
the plugin's sanitization, validation, and hooks run. Ergonomic verbs **load current state →
apply the caller's delta → persist the whole property**, so a partial edit never clobbers the
rest. Form fields live as `[form-tags]` inside the `form` string (there is no structured field
store), so `src/Adapter/Cf7TagBuilder.php` builds/locates/merges those tokens and saves the
template back — taking care to emit every option/flag before any quoted value, which CF7's
scanner requires.

See `coverage/coverage-report.md` for the full surface/task map (and what's excluded and why:
submission storage belongs to the separate Flamingo plugin; third-party integrations need
external API keys).

```
  forms.php  fields.php  mail.php  messages.php  settings.php  validate-submit.php

  inventory.json        structured understanding backing the coverage claim
  coverage-report.md    surface/task → ability (or excluded-with-reason) map
```
